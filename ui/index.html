Every name, two worlds.

This browser asks the community Free Registry first. If the name is not there, it falls back to the public web. If it is in both, you choose.

Registry records are public and PR-reviewed at github.com/free-domain-name/registry. Public sites that send X-Frame-Options may refuse to render here — use the external-open button in that case.

How claiming works

  1. Fork free-domain-name/registry.
  2. Create d/e/n/e/name.fdn.json with this record: 

              

                An IP address is enough — like an A record for HTTP.
                No domain or DNS record is needed. Replace
                203.0.113.10 with your server's public IP
                (add :port if needed). Keep this an
                origin: no path, query or fragment — the browser
                appends the visitor's path. Use http:// for
                a bare IP; HTTPS certificates are issued to names, not addresses.
              

              

                CI checks the shard path, the four fields, the target URL and the TTL.
                When the target is an IP, the browser sends the free name as
                Host, so one address can serve many names.
